# 香港骨位 KML File (Google Maps)
根據易出行製作的香港骨位的KML檔案, 可供Google map 使用. 

A KML file about Hong Kong On-Street Motocycle Parking according to the data from HKeMobility, it can be used by Google map.

#### 注意: 由於Google Maps的上載容量有限, 沒法確保所有骨位地點齊存, 而且本人不會更新此地圖, 有需要者可運行toKML.py取得motorcycleParking.kml，再以相關應用程式開啟檔案（如：Google Earth）以取得全部骨位資訊。

#### Note: Due to the limited upload file size of Google Maps, not all the On-Street Motocycle Parking locations are included, and I will not update this map. If necessary, please run the toKML.py and access the motorcycleParking.kml with an accessible app like Google Earth.
